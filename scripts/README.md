# Scripts Directory

Utility scripts for MemGraph development and setup.

## Available Scripts

### `generate-api-client.js`
Generates TypeScript API client from OpenAPI schema.
```bash
node scripts/generate-api-client.js
```

### `init-agents.js`
Initializes sample agents for testing/development.
```bash
node scripts/init-agents.js
```

### `list_models.py`
Lists available Gemini/LLM models.
```bash
python scripts/list_models.py
```
